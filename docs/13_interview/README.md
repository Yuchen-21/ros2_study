# Stage 13 — ROS2 中间件工程师 100 问（规划）

重要度：⭐⭐⭐　预计：持续复习　依赖：所有机制阶段

## 题库结构

| 类别 | 数量 | 重点 |
|---|---:|---|
| 基础 | 25 | process/thread、ROS2 分层、DDS 实体、基本 QoS |
| 中级 | 25 | discovery、executor、history、serialization、网络 |
| 高级 | 25 | tracing、tail latency、SHM、real-time、源码与故障 |
| 系统设计 | 25 | 多传感器架构、容量、SLO、故障域、bridge、演进 |

每道题包含：

1. **30 秒回答**：结论 + 最重要的边界；
2. **2 分钟回答**：因果链 + 工程例子；
3. **深入追问**：版本/RMW 差异、证据、反例和 trade-off；
4. **常见失分点**：术语混淆或无条件绝对化；
5. **验证实验**：指向仓库 lab。

## 评分维度

- 技术准确性 40%；
- 因果链与边界 25%；
- 工程证据 20%；
- 表达结构 10%；
- 主动声明前提 5%。

Stage 01 的首批三层答案位于[Linux IPC 面试题](../../interview/stage1_linux_ipc.md)，后续阶段逐步扩充到 100 问。

## 【求职价值】

30 秒版本用于面试首答，2 分钟版本展示系统理解，深入追问检验是否真的做过测量与排障。三层答案防止“一上来倾倒全部知识”。

## 完成定义

- [ ] 随机 20 题首答不超过 40 秒。
- [ ] 深挖时能画图、举 trace/pcap 证据并说明前提。
